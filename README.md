## Miniatur Atap Otomatis Berbasis Mikrokontroler Berdasarkan Intensitas Cahaya dan Kondisi Cuaca
Proyek miniatur atap rumah otomatis berbasis ESP32 yang menggunakan metode Fuzzy Logic untuk menentukan respons atap berdasarkan kondisi cahaya dan hujan. Sistem terintegrasi dengan platform IoT Blynk untuk memantau kondisi sensor secara real-time dan memberikan kontrol manual terhadap mekanisme atap.

## Fitur
  •	Mendeteksi intensitas cahaya menggunakan sensor cahaya.
  
  •	Mendeteksi kondisi hujan menggunakan sensor hujan.

  •	Menentukan respons atap menggunakan metode Fuzzy Logic.

  •	Mengendalikan mekanisme buka dan tutup atap menggunakan motor DC.

  •	Memantau kondisi sensor melalui platform Blynk.

  •	Mengontrol atap secara manual melalui aplikasi Blynk.

## Teknologi
  •	Mikrokontroler: ESP32
 
  •	Bahasa Pemrograman: C++ (Arduino framework)
  
  •	Metode Kendali: Fuzzy Logic
  
  •	Platform IoT: Blynk
